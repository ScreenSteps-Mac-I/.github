## Why It Happens

screen and a finished document, and small mismatches in resolution, order or anchoring show up only at export
time. A screenshot that looks fine on your Retina display can soften when scaled into a PDF; a callout you
placed perfectly can drift if the underlying image is swapped. screensteps for mac keeps each step as a
structured unit — capture, annotation and caption together — which is exactly why fixing these issues is
usually a matter of re-checking one step rather than rebuilding the whole guide.

The export format matters too. download screensteps for mac can produce both PDF and HTML from the same
source lesson, but they render differently: PDF is fixed-layout and print-friendly, while HTML reflows for
the web. Problems that look like bugs are often just the wrong format for the job — a guide meant for a help
site should be authored and exported as HTML, not lifted out of a PDF.

the resolution you'll actually export to. Annotate immediately after capturing, while the layout is fresh, so
